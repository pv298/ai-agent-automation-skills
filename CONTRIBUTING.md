# Contributing

Thank you for helping improve this collection of AI agent and automation skills.

## What makes a useful contribution?

- A clear task and intended user.
- Practical prerequisites and required permissions.
- A step-by-step workflow that can be followed.
- Example inputs and expected outputs.
- Error handling, retries and recovery guidance.
- Security, privacy and human-approval considerations.
- A test or validation method.

## Skill format

Create a folder under `skills/` and add a `SKILL.md` file. Include YAML frontmatter with a short, lowercase, hyphenated `name` and a clear `description` that says what the skill does and when to use it.

## Please avoid

- Publishing API keys, credentials, private URLs or customer data.
- Presenting untested examples as production-ready.
- Instructions that bypass access controls, platform policies or consent.
- Unsafe destructive actions without confirmation and recovery steps.
- Copied documentation or unlicensed assets.

## Before submitting

1. Test commands and code examples where practical.
2. Mark placeholders and assumptions clearly.
3. Include expected outcomes and failure cases.
4. Check links and spelling.
5. Explain any platform or version dependencies.

Contributions may be edited or declined to keep the library safe and useful.
